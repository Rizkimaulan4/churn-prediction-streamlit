# 📊 Customer Churn Prediction App

Aplikasi berbasis Machine Learning untuk memprediksi apakah seorang customer akan churn atau tidak.

Aplikasi ini dibangun menggunakan Streamlit dan dapat dijalankan secara lokal maupun online.

---

## 📌 Overview
Project ini bertujuan untuk:
- Mengolah data customer
- Membangun model prediksi churn
- Menyajikan hasil dalam bentuk aplikasi web interaktif

---

## 🚀 Features
- Input data customer secara manual
- Prediksi churn secara real-time
- Visualisasi hasil (tabel & grafik)
- Multi-page app (Overview, Prediction, Analysis)

---

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Joblib
